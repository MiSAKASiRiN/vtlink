## DUML 外层


| 偏移 | 长度 | 字段                                                |
| ---: | ---: | --------------------------------------------------- |
|    0 |    1 | `0x55`                                              |
|    1 |    2 | 总长度低 10 bit，当前封装 OR`0x0400`；总长 13–1023 |
|    3 |    1 | 前 3 字节 CRC8                                      |
|    4 |    1 | sender：VT12`0x8A`，VT13 `0xAA`                     |
|    5 |    1 | receiver，按命令选择                                |
|    6 |    2 | sequence                                            |
|    8 |    1 | flags，参考请求为`0x40`                             |
|    9 |    1 | command set                                         |
|   10 |    1 | command id                                          |
|   11 |    N | payload                                             |
| 11+N |    2 | 前面所有字节 CRC16                                  |

DUML CRC8 初值 `0x77`、反射多项式 `0x8C`；CRC16 初值 `0x3692`、反射多项式 `0x8408`。本包算法无末尾异或。解析器先校验头和长度，再校验整帧；支持噪声、断包、粘包。

## A5 业务帧

`A5 | payload_len:u16 | seq:u8 | header_crc8 | command:u16 | payload | crc16:u16`

头 CRC8 覆盖前 4 字节，初值 `0xFF`，多项式 `0x8C`；尾 CRC16 初值 `0xFFFF`，多项式 `0x8408`。总长为 payload 长度 + 9。下面的 type-2 传输段将整个 A5 业务帧作为内容封装。

## Type-2 下行传输段

`SOF | length:u16 | crc8 | type=02 | A5业务帧 | timestamp_ms:u16 | transport_seq:u16 | crc16:u16`

- `SOF=0xA5`：A5/type-2 传输格式，length 包含业务帧和 4 字节尾部；CRC8 计算使用线上这三个头字节。
- `SOF=0xAA`：AA/type-2 传输格式，线上 length 同样包含 4 字节尾部，但 CRC8 必须使用**尚未加 4 的业务帧长度**构造头来计算。
- 传输 CRC8 初值 `0x77`，CRC16 初值 `0x1862`；多项式分别为 `0x8C`、`0x8408`。
- 毫秒时间和传输序号按 uint16 回绕，业务帧序号按 uint8 回绕。

下行段置于 DUML `09/63`，receiver `0x77`。30 字节业务数据对应 39 字节 A5 帧、50 字节传输段和 63 字节 DUML 帧。

VT12 下行必须包含 4 字节尾部，发送端会在输出 UART 业务数据前移除它。当前编码器负责生成尾部、更新传输长度并计算 CRC。

本包提供 A5/type-2 和 AA/type-2 传输格式的编码。上行解析器校验已支持的传输类型，遇到未知类型时返回错误。

## VT12 配置与状态


| set/id  | 请求/载荷                     | 已记录行为                           |
| ------- | ----------------------------- | ------------------------------------ |
| `09/61` | 空                            | 模式查询；应答前两字节为结果码、模式 |
| `09/60` | 模式字节                      | 模式设置；公开便捷 API 未封装此命令  |
| `09/0D` | `0F valueX:u16 11 valueY:u16` | 接收端两个信道配置项                 |
| `09/40` | 设备推送                      | 三字节 tag/value 状态组              |
| `09/55` | `00 00`                       | 软件重启；会中断 USB                 |
| `09/63` | 传输段                        | 主机下行                             |
| `09/62` | 设备数据                      | 主机上行入口                         |

主 SDK 只公开已常用的 1–6 信道：


| 信道 | 配置值   | 信道 | 配置值   |
| ---: | -------- | ---: | -------- |
|    1 | `0x09F2` |    4 | `0x0A34` |
|    2 | `0x0A08` |    5 | `0x0A4A` |
|    3 | `0x0A1E` |    6 | `0x0A60` |

模式与信道应读取实际设备状态，不在连接时自动覆盖。`09/40` tag 6 的值 4 曾表示无线连接，tag 15 为频率配置值，tag 7/12 为速率/温度原始值。速率和温度保留原始值显示，工程单位换算按固件字段定义实现。

配置流程依次记录发送、匹配 ACK、频率状态回读和视频恢复。对频时将 X/Y 设置为相同信道；状态推送按实际提供的字段显示回读值。

## 自定义数据通路


| 接口              | 业务命令 | payload | 外层                          |
| ----------------- | -------- | ------: | ----------------------------- |
| VT12 当前参考下行 | `0x0302` |    30 B | sender 8A，09/63，receiver 77 |
| VT13 当前参考下行 | `0x0311` |    30 B | sender AA，09/63，receiver 77 |

两个自定义编码入口均要求 30 字节 payload，并逐字节保留其内容。上行先检查 DUML 地址、命令及 CRC，再按 raw-A5 或 type-2 解码；未知传输类型返回错误。

## VT13 键鼠报告

DUML `3F/11`，sender `AA`，同一载荷分别发送到 receiver `06` 和 `0E`。13 字节布局如下：


|      偏移 | 类型 | 含义                                           |
| --------: | ---- | ---------------------------------------------- |
|         0 | u8   | sdr，参考值 0                                  |
| 1 / 3 / 5 | i16  | mouse x / y / z                                |
|         7 | u8   | 左键 bits 0–1、右键 bits 2–3、中键 bits 4–5 |
|         8 | u8   | keys 低 8 bit                                  |
|         9 | u16  | ssfn，参考值 0                                 |
|        11 | u8   | keys 高 8 bit                                  |
|        12 | u8   | reserved，0                                    |

keys bit 0–15：W、S、A、D、Shift、Ctrl、Q、E、R、F、G、Z、X、C、V、B。编码函数返回待发送字节，发送周期由应用层调度。

VT12 的键鼠接口不同：A5 `0x0304`、12 字节 `<hhhBBHH>`，分别为 x/y/z、left/right、keys、reserved，经带尾部 type-2 和 DUML `09/63`。VT12 和 VT13 分别使用各自的键鼠编码函数。

## VT02 单机型信道 UART

使用 A5 帧：`0x0F01` 一字节信道 1–6；`0x0F02` 空载荷查询。已保存资料的设置/查询上限分别为 1 Hz/2 Hz；此包只复核已有报文向量，未进行 UART 电气和实机发送验证。它不经接收端 USB CDC 的 DUML 封装。
