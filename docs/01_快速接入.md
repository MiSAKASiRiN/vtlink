# 快速接入

[返回开发包](../README.md)

以下命令均从开发包根目录执行。将 `python` 替换为已经安装依赖的虚拟环境解释器。先关闭占用同一 USB 接口、Protocol 串口或 UDP 8080 的程序。USB 已枚举、无线已连接、码流已同步是三个独立状态。

## 1. 准备环境

```sh
python -m pip install -r requirements.txt
python -m vtlink ports
```

PyUSB 还需要与 Python 架构匹配的系统 libusb；macOS 常用 `brew install libusb ffmpeg`，Linux 可由系统包管理器安装 `libusb-1.0-0`、`ffmpeg`。macOS 的 VT13 实时窗口使用 `ffplay`。VT12 系统网卡入口的窗口预览使用 Tk；不需要窗口时使用 `--headless`。

串口列表只做枚举，不打开端口。按 VID/PID、物理 USB 路径和接口号识别设备，再选择对应的 COM、`ttyACM` 或 `usbmodem` 端口。多台同型号设备时使用物理 USB 路径区分。

## 2. VT12：Windows / Linux 系统网卡

确认 RNDIS 网卡属于 `2CA3:001F`，给该专用网卡配置 `192.168.42.105/24`；设备地址为 `192.168.42.2`。该接口不需要默认网关或 DNS。下面的接收命令不修改系统网络配置。

```sh
python tools/vt12_video.py --headless --seconds 15 --record --output work/vt12/capture
python tools/vt12_video.py
```

若需要观察硬件状态，在另一终端显式选择 VT12 CDC：

```sh
python examples/serial_monitor.py --family vt12 --port /dev/ttyACM0 --query --seconds 10
```

Windows 把示例端口替换为实际 COM 号。`--query` 发送一次模式查询；不修改信道。信道设置的生成与实际写入方法见 SDK 文档。

## 3. VT12：macOS 用户态 RNDIS

```sh
python tools/vt12_macos_rndis.py --preview --seconds 0
```

浏览器打开控制台输出的本机地址，默认 `http://127.0.0.1:18712`。该工具 claim 接口 0/1，初始化 RNDIS、发送 ARP 并接收 IP/UDP；不创建系统网卡，不发送串口配置或自定义数据。Ctrl-C 退出并释放接口。该浏览器预览适合接入检查，显示延迟包含 JPEG 编码和浏览器刷新耗时。

Linux 已绑定 RNDIS 内核驱动时使用上面的系统网卡入口，不对接口 0/1 强制解绑。

## 4. VT13：macOS 实时预览

```sh
python tools/macos_preview.py --rotation 0 --seconds 30
```

自动识别唯一设备的视频接口和 Protocol CDC，持续读取 HEVC，必要时发送固定关键帧请求及取消。Q/Esc 或关闭窗口退出。`--rotation 180` 仅改变画面显示。默认不发送键鼠或自定义数据。该工具使用 macOS IORegistry 识别设备，运行平台为 macOS。

## 5. VT13：Linux 接入与裸流采集

```sh
python tools/capture_vt13.py --list
python tools/capture_vt13.py --seconds 30 --output work/vt13.h265
```

第二条命令只采集视频，不打开串口。若中途接入没有完整参数集/关键帧，保持采集运行，在另一终端显式请求一次：

```sh
python examples/serial_monitor.py --family vt13 --port /dev/ttyACM0 --keyframe --seconds 5
```

`--keyframe` 发送请求，约 150 ms 后取消。实际端口必须是 Protocol CDC。不要在已有预览程序拥有该串口时运行此命令。裸流可交给 `ffplay -f hevc work/vt13.h265` 离线查看；流起点缺少参数集时须先找到完整同步点。

## 6. 无设备复核

```sh
python tools/validate_offline.py
python tools/verify_integrity.py
```

第一个命令检查当前协议固定向量、两种视频样本和包内文档链接，将结果写入 `work/offline-validation/`。这两条命令不打开 USB 或串口。
